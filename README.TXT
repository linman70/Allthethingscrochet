ALL THINGS CROCHET — WEBSITE FILES

HOW TO USE
1. Extract this ZIP file.
2. Keep index.html, amigurumi.html, tips.html, patterns.html, style.css and logo.svg together in the same folder.
3. Double-click index.html to open the website in your browser.
4. Use the navigation menu to move between all four pages.

The pages use remotely hosted Unsplash image URLs, so an internet connection is needed for photographs.
The image URLs are examples and may be replaced with other free-to-use images. Review each image's source and license before publishing commercially.
The site is a static HTML/CSS website. To publish it online, upload all files together to your web host.
